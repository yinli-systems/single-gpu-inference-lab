# Section 6: bounded evidence-gated execution

Frozen before new GPU timings. A/B diagnostics use six exposed geometries, not a fresh validation set. Two one-GPU allocations, one per family; each runs three fresh Python processes per version on the same allocated device. First 0.6.18, then separately pinned 0.7.0, provided the adapter structural and numerical contracts pass. Version ordering is not randomized: cross-version ratios are descriptive, not causal version-effect claims.

A: identity_label and identity_copy controls receive the same descriptor bytes, copies, validation and timing path as candidates. For each cell, 12 balanced ABBA/BAAB blocks, no optional stopping. Events are initialized before timing; CPU affinity remains within the allocated mask. Report graph-one, graph32 steady, eager-one and graph-one after a 128-MiB write separately. Cache pressure is not proven cache eviction. Do not pool single-call and steady regimes.

Control resolution target: 90% hierarchical process/block interval for each no-op control must fit native/candidate [1/1.005,1.005] before a 1% decision is interpreted at that cell. Failing this is unresolved, not evidence of an algorithm regression. Original failures are retained. No global 1% guarantee; cellwise intervals are not multiplicity-adjusted. All rows retained. GPU clocks are observed, not changed; no whole-node exclusive claim.

B: only descriptor bijections change. Full output and LSE must remain exact, sampled independent FP32 references precede timings. The exposed two-request reversal is the mechanism target. Capture separate profiler kernel symbols/launch metadata AFTER unprofiled measurements. Profiling does not enter timing tables; lack of hardware counters leaves hardware-cause attribution unresolved.

C: 0.7.0 is an isolated wheel overlay, not a shared runtime upgrade. Pin wheel and wrapper hashes before use. Verify each actual plan and numerical output; source-applicability is not qualification. FA2 introspection is not a proof of superiority over auto or another backend. Paged/current-auto extension is separately qualified before use.

D/E: no new dispatcher is promoted from diagnostics. Require all applicable A controls, independently confirmed net native plan-plus-run benefit and pristine upstream comparison before applying a candidate to a full engine. Unsupported contexts stay default-off. If earlier gates fail, close D/E explicitly as BLOCKED, do not manufacture a serving result or rename exposed cases as holdouts. Complete feasible diagnostics and publish evidence even on failure.

Total bounded allocation: two GPU jobs, each at most 35 minutes. No duplicate submissions after timeout. No unrelated jobs modified. No deletion of historical data. Current source and immutable receipts are retained.
