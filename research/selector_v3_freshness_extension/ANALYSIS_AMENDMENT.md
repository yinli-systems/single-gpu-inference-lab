# Strict-freshness extension analysis scope

This directory is a separately preregistered, two-case sensitivity extension. It does not modify the selector rule or the original 30-case primary campaign bound to measurement commit `8edd481c9f43be76b82a4c77a37930f34df0a7d2`.

The extension analyzer inherits the fail-closed environment, source, exact-output/LSE, eager/Graph1/Graph16, control-resolution, worst-case, and joint-min contracts from selector-v3. Its standalone gate is **non-promotional**: even a pass cannot set `single_gpu_release_gate_pass`, launch serving validation, or erase a failed primary gate. A later combined sensitivity must identify both immutable campaign roots and reconstruct its bootstrap draws from raw evidence rather than copying point estimates.
