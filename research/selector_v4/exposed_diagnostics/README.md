The frozen v4.2 canary5090 is HOLD. Candidate-native/pristine worst0.931804 and joint95%LCB0.926743 are below the unchanged0.99 floor. Selected resource gains do not override this result. Some regressions also occur in pure graph device timing, so a host-overhead explanation alone is insufficient. The cause is not established.

`native_context.py` examines three already-consumed configurations from canary03/07 using current-main private resource modules, one native wrapper, and shared input/output/metadata/workspace pointers. It separately measures native/native after resource conditioning, uncertified fallback versus direct native, and native/resource. The protocol requests 24 balanced ABBA/BAAB blocks,384ms native-fixed target windows,120ms minimum windows and three independent process repetitions. All persisted data are retained. Native compiled-library hashes, original module, plan, numerical output and LSE are checked. Exact warmup/conditioning boundaries are in the archived script. GPU contexts/conditioning before a scored window are diagnostic interventions; resource execution explicitly bypasses deployment certificate selection to measure the candidate, and is not authorized serving.

Eager measures the prepared wrapper call. Graph1/16 measure pure replay. These trials do not certify planning, scheduler/input updates, full serving, fresh generalization, or the old token differences. Different current-main sources and buffer ownership mean that these diagnostics cannot retroactively change the frozen0.7.0 canary result. Release48/stress12 stay untouched while HOLD persists.

Source, buffer layout, conditioning and device allocation differ from the frozen v4.2 campaign, so no single cause of its regressions is established.

`analyze_native_context.py` resamples independent processes and then all paired blocks, checks raw source/file identities and ABBA positions, and summarizes both wall/device timing. Strict mode requires complete data. `--allow-incomplete-diagnostic` is a separate explicit diagnostic option that records missing evidence and still supplies no qualification authority. The statistical tests verify that between-process uncertainty is retained even when all within-process blocks are constant.

Future `native_context.py` bindings persist each complete four-window block to `raw-windows.jsonl` with fsync outside scored windows, save numerical metadata before timing, and checkpoint after every comparison. The original campaign script and raw results remain unchanged.
